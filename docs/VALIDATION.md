- 实际拖动抛物线投掷、投偏、失败三次后的轨迹辅助、真实命中和开门。
- 横向树枝不能过门，连续角度投影宽度判定；四次摸狗反应、花束获得。
- 相册立即打开、翻页、重新打开；卡片拖入、旋转、错误路线及经过花朵的图连通解法。
- 轨道错误分支进入回收区再回顶部，正确左／右／右分支到达杯子，拉杆出餐。

- 静音保存、刷新续玩、横竖屏操作、无脚本异常及游戏资源 404。

移动端另有 21 项检查全部通过，使用 Chrome DevTools 原生触摸事件。检查了真实触摸投掷取消／失败／命中、树枝拖转与按钮替代操作、拒绝音频时保留字幕、字幕正在显示时的竖屏瞄准、44 px 触控按钮、全屏相册与路线卡，以及 390×844 页面无横向或纵向溢出。

规则测试穷举了全部 64 种路线卡旋转和 8 种轨道设置，同时验证预测与运动共享重力、连续碰撞、合理树枝角度区间、路线必须经过花朵。字幕测试覆盖替换、取消、跳过、序列推进及独立字幕隐藏。
